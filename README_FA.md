# SeaDocs — نسخه اولیه اندروید

این پروژه یک اسکلت اجرایی اندروید با Kotlin، Jetpack Compose و Room است.

## امکانات فعلی
- داشبورد شمارش کشتی‌ها، دریانوردان و مدارک
- ثبت و نمایش کشتی (نام، IMO، پرچم)
- ثبت و نمایش دریانورد (نام و سمت)
- ثبت مدرک، دسته‌بندی، مالکیت کشتی/دریانورد، تاریخ انقضا
- انتخاب فایل PDF یا تصویر از حافظه گوشی
- فهرست هشدار مدارک منقضی یا دارای انقضا در ۹۰ روز آینده
- تغییر زبان رابط فارسی/انگلیسی
- ذخیره‌سازی محلی آفلاین با پایگاه داده Room

## ساخت APK
1. Android Studio نسخه جدید را نصب کنید.
2. پوشه SeaDocs را باز کنید.
3. اجازه دهید Gradle همگام‌سازی و وابستگی‌ها را دریافت کند.
4. از منوی Build گزینه Build APK(s) را اجرا کنید.
5. فایل خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## نکات مهم پیش از استفاده عملیاتی
این نسخه، نمونه اولیه محلی است و هنوز سرویس ابری، ورود کاربران، نقش‌ها و مجوزها، همگام‌سازی چنددستگاهی، رمزنگاری فایل‌ها، اعلان زمان‌بندی‌شده سیستم و پشتیبان‌گیری خودکار ندارد.
برای جلوگیری از گم‌شدن فایل‌های پیوست، فایل‌ها فعلاً از طریق انتخاب‌گر اندروید انتخاب می‌شوند؛ در نسخه بعد باید کپی امن فایل‌ها در فضای اختصاصی برنامه و مدیریت دسترسی‌ها اضافه شود.
تاریخ انقضا را با قالب میلادی `YYYY-MM-DD` وارد کنید.
